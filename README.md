
# Jenkins Demo

A beginner project for learning Jenkins and CI/CD automation.

## Project Files

- `app.py` - A simple Python application.
- `Jenkinsfile` - Defines the Jenkins Pipeline.
- `README.md` - Project documentation.

## Purpose

This repository is used to practise:

- Git and GitHub integration with Jenkins
- Pipeline as code
- Automated build and test stages
- Build artifact archiving

## Pipeline Workflow

1. Checkout source code from GitHub.
2. Build the application.
3. Test the build output.
4. Archive build artifacts.

## Learning Environment

- Git and GitHub
- Jenkins
- Linux shell commands
